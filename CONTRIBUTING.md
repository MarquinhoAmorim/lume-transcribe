# Contribuindo com o Lume Transcribe

1. Crie um fork e uma branch para sua alteração.
2. Instale as dependências com `pip install -r requirements.txt` e `npm ci`.
3. Rode `npm run build` e `npm run test:backend` antes de abrir o pull request.
4. Explique o comportamento alterado e inclua passos para reproduzir qualquer bug corrigido.

O projeto deve continuar local-first: arquivos de áudio e vídeo não devem ser enviados para APIs pagas ou serviços externos.
